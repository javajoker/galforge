# GalForge — Documentation

**GalForge** is a framework + open data standard for generating **gal-games**
(visual novels / dating sims) from structured, engine-agnostic data: image / BGM /
voice resources, character definitions, conversations, and scene scripts.

The standard is designed to be **authored by humans or generated by AI**, validated
by schema, and played by any conforming runtime (web, Ren'Py exporter, Unity, etc.).

## Key design constraints (normative highlights)

These cross-cut every document and are enforced by the standard:

- **Two-character stage limit** — at most **two** character sprites are visible at
  once. Scenes with more participants use **alternating display** driven by who is
  speaking. See [Script Standard §6](spec/script-standard.md#6-stage-model--the-two-character-rule).
- **Transition effects** are first-class on every visual change. See [§7](spec/script-standard.md#7-transition-effects).
- **Facial expressions & clothing** are layered sprite states, swappable mid-line.
  See [§5](spec/script-standard.md#5-characters--layered-sprites).
- **Item close-ups** are a first-class command. See [§8.10](spec/script-standard.md#810-closeup--item-close-up).
